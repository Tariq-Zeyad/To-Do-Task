# 📋 TaskFlow - Task Management App

A simple and modern To-Do application built with vanilla JavaScript.


---

## 📝 About The Project

TaskFlow is a task management application developed for Web Development 1 course (Week 09) at Al-Aqsa University.  
The project focuses on **DOM Manipulation & Events** using pure JavaScript.

---
## 🛠️ Built With

- HTML5 — Semantic structure  
- CSS3 — Modern styling with animations  
- JavaScript (ES6+) — Application logic  
- Font Awesome — Icons  
- Google Fonts — Inter font family
